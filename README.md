# SS-Assistent

A personal Android assistant by S•S.

## Current stage

The first Android app shell is now in place with a dark, deep-purple UI.

Planned modules:

- Local AI model manager
- Assistant chat and actions
- Human-confirmed send/edit/delete workflow
- Android app and text automation
- Memory system
- Later integration with the other S•S AI apps

## Models

Large model files such as `.gguf` files are intentionally **not** stored in this repository. Models will be added locally through the app's model manager in a later stage.
